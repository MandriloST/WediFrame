    - Gate: `!Enabled` ili prazan `ClientId` → **404** (feature off/nekonfigurirano → frontend skriva gumb).
    - Verifikacija: `GoogleJsonWebSignature.ValidateAsync(idToken, ValidationSettings{ Audience=[ClientId] })` — potpis (Google JWKS), `iss` (accounts.google.com), `exp`, `aud`. `InvalidJwtException`/network → **401 `auth.google_invalid_token`**.

    - Matching: **(1)** po `GoogleSubjectId == sub` → `auth.google_login`; **(2)** inače po **verificiranom emailu** — ako je `GoogleSubjectId` prazan → postavi `sub` + `EmailVerified=true` → `auth.google_linked`, inače (već linkan na drugi sub, anomalija) → login bez diranja linka; **(3)** inače **kreiraj** usera (passwordless, `EmailVerified=true`, `GoogleSubjectId=sub`, `Role=Host`, jezik iz `payload.Locale?.Split('-')[0]` → `NormalizeLanguage`) → `auth.registered_via_google`.
    - `ITokenIssuer.IssueSession` izda istu sesiju kao login; audit red; **race-safe**: `DbUpdateException` (unique Email/GoogleSubjectId na prvom sign-inu) → `ChangeTracker.Clear()` → re-resolve po `sub||email` → retry.
  - Contract `GoogleSignInRequest`. `GoogleAuthOptions` registriran u `IdentityModule` (`AddOptions().Bind`). `appsettings.json` +`Auth:{Google,MagicLink}` stub (surgički string-insert nakon `Jwt`; `RateLimiting` blok netaknut, JSON valjan). `.http` +google primjer (placeholder token + napomena da pravi dolazi iz Koraka E).
  - **Nije kompajlirano** (nema .NET SDK) — ručno provjereno: code-only balans (parens 235/235, braces 59/59 nakon strip-a komentara/stringova — +3 `)` iz raw grepa bili su u komentarima), `using Google.Apis.Auth`, ruta+handler+`GoogleInvalidToken` helper ožičeni, appsettings valjan i minimalan diff, kolone (`GoogleSubjectId`/`EmailVerified`/nullable `PasswordHash`) već iz Koraka A → **nema migracije**, jedini novi `new User` (kreiranje) postavlja `Email`.
  - **Korisnik lokalno:** `git pull` → `dotnet build` (restore povuče `Google.Apis.Auth 1.75.0`; ako odbijen → bump na najnoviju 1.x u `Directory.Packages.props`) → **Google Cloud Console**: APIs & Services → Credentials → Create Credentials → OAuth client ID → **Web application**; Authorized JavaScript origins `http://localhost:3000` (i kasnije `https://wediframe.hr`); kopiraj **Client ID** (`…apps.googleusercontent.com`, bez secreta) → postavi `Auth:Google:Enabled=true` + `Auth:Google:ClientId=…` (dev: `appsettings.Development.json` ili user-secrets) → `dotnet run`.
